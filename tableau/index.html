About CV Tableau tool

Tableau maker

Here's a tool I vibecoded so that I could easily typset OT, HG and MaxEnt tableaux in LaTeX and Typst. Feel free to use it for your own purposes as well.

After you create your tableau, you can copy it into LaTeX, Typst, Word, Google Docs or Markdown, or download it as an image. There's also an option to automatically calculate rankings, harmony scores and MaxEnt probabilities, but you'd probably be better off calculating that yourself and using this as a simple typsetting tool.

Tableau

Tips for filling in the tableau
  • Violations: type a number (2) or stars (**), and add ! for a fatal violation (*!). Leave a cell empty for no violations. Enter and the arrow keys move between rows.
  • Winners: pick ☞ (or ☹, 💣, ✗) for a candidate in the Mark column.
  • Shading: turn on Shade cells, then click the cells to shade. You can also click cells in the preview.
  • Subscripts and superscripts: Max_{IO} gives a subscript and X^{2} a superscript, in constraint names, inputs and candidates. Constraint names get small caps automatically.
  • Unranked constraints (OT): the ┆ button puts a dashed line between two neighbouring constraints.
  • Spreadsheets: you can paste a block of cells copied from Excel or Google Sheets into the grid, or import an OTSoft file.
Experimental: compute results automatically

Normally the tool only typesets what you type. With this on, it works out the winners (☞), fatal violations (!), shading, harmonies and probabilities from the violations and weights, and checks the winners you intend (tick Intended). Turning it off again keeps the current marks and values, so you can carry on by hand.

Display options

Export

Uses Typst's built-in table, so no packages are needed.

Copies the tableau as a real table, with its lines, shading, small caps and IPA as Unicode text. Paste it into Word, Google Docs, LibreOffice or Pages, where you can still edit it. For the IPA to show up, the document needs a font with IPA letters: Charis SIL and Andika are free, and Google Docs has both.

A Markdown table with Unicode IPA. Markdown tables can't span cells, shade them or draw dashed lines, so those are left out.

PNG works anywhere, including slides. SVG stays sharp at any size and has the font built in.

Tab-delimited input for OTSoft, and for the Maxent Grammar Tool after light editing. The frequency column holds the observed values, or 1 for the winner.

Hasse diagram

Draw a constraint ranking as a Hasse diagram, with the constraint names formatted as in the tableau.

Symbols

Click a field in the tableau, then click a symbol.

Import

Choose a file you saved here (.json) or an OTSoft file (tab-delimited .txt). You can also paste either format, or cells copied from a spreadsheet in OTSoft layout: two header rows with the constraint names in column D onwards, then input, candidate, frequency and violations.
