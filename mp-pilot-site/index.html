Sentence choice study: review copy

Thank you for looking this over. This is a private copy of a short online experiment, set up so you can check that it runs properly and that the sentences read well. Nothing you do here is collected: each part saves a file to your computer, and you send the files to Mika.

Run the experiment

Take part as a participant would. It takes 15–20 minutes and needs a keyboard, so use a laptop or desktop. At the end a CSV file downloads. Please note anything that looked wrong, confusing or too fast, and whether the instructions made the task clear.

Each run shows one of four versions, chosen at random, and each version contains about a quarter of the sentence pairs. To see a particular version, open 1, 2, 3 or 4.

Review the sentences

Every item in the study on one page, including the ones your run did not show. Mark each as fine or flag it, with a comment if you like: unnatural wording, an unclear context, a choice where both options sound wrong, anything like that. Your marks are kept in this browser, so you can stop and come back. When you are done, download your comments as a CSV.

This page is not listed anywhere and asks search engines not to index it. It will be taken down after the review.
